## 放弃了什么（以及为什么不选）

- **闭卷（不内联文档）**：第一轮 0/39 测的是「找不到题面点名的文档」，不是能力。
- **按与 gold patch 的重合去剥题面**：拿答案筛题面，尺子和被测对象同源；换 gold patch 就要重算。按代码块切是结构规则（42 行泄漏里 41 行在代码块内）。
- **重写自包含题面**：39 题人工改写 + 复核，并且丢掉「真实祈使句」这个定位。留作 v0.3 的 20 题试点。
- **把审计题改写成要求 diff**：改写时必须点名改哪一项，等于把答案写进题面。
- **改 `--runs` 默认值**：会断掉第一轮的复现，已有契约测试锁着。
- **改写 `survivors.json` / `category`**：前者是 37.8% 那批的分母，后者被 t3/t9/pipeline 读取。
- **只把 `bunfig.toml` 加进还原名单**：`git checkout --` 在 agent commit 过之后会还原出 agent 的版本（容器实测），所以必须按 blob sha 还原。
- **在 `tasks/` 里互换两份题面**：harbor 只读 `instruction.md`，但互换会让 provenance 改名、旧复现链断掉。改为导出派生目录。
- **T0009 改挂载投递**：要动 sid-code 适配器（`sid_code_agent.py:781`），影响所有 Harbor 实验，另立待办。
