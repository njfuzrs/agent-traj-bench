# T13：§3.3 功效表与 §5.2 S/ε/m 阈值表落成脚本

方案文档：docs-research `sid-code/bugfixes/todo/20261003-评测接入CI-CD-分层门禁与基线闭环.md`
§3.3（题量与统计功效）、§5.2（L2 判定规则）、§6.6 T13（本任务的定义与判据）。

## 决定了什么

1. **三张数字表由 `scripts/eval-stats.py` 生成**，文档只引用输出：
   - §3.3 表① 不配对：题量 → 可检出最小差距（两比例 arcsine 正态近似）；
   - §3.3 表② 配对：翻转率 → 不一致题数 / 最小显著分割 / 净回退（McNemar 精确检验）；
   - §5.2 m 表：\|S\| × ε → 阻断阈值 m 与检出概率（精确二项尾概率）。
2. **口径写死在模块常量**：α=0.05 双侧、功效 0.8、基线 p=14/37、ε 下限 0.10、|S| 下限 6。
   改它们 = 改判据，必须走 review。
3. **尾概率用精确有理数**（`fractions.Fraction` + `math.comb`），不用浮点：
   `|S|=10、ε=0.15` 的 P(X≥4)=0.04997，离 α=0.05 只有 **3e-5**，浮点实现的成败取决于累加顺序。
4. **`--check` 与文档冻结值逐格对账**（`DOC_*` 常量是文档镜像），并进 CI（gate16）+ 单测清单。
5. **配对表按 T00 裁决后的新题量 32 题重算**，不沿用 37 题旧表（文档 §6.6 T00 裁决原文要求）。
6. **§5.2 三个冻结量由同一脚本从真实基线算**：`--baseline`（k 份 `trials.json`）→ S、
   `--holdout` → ε、`block_threshold()` → m，供 T15 → T16 → T17 直接调用，T17 只需写回数字。

## 放弃了什么（以及为什么不选）

- **不引 scipy**：只用 stdlib。仓库 gate10 已把「零第三方依赖」定为纪律，统计脚本没有理由例外；
  CI 也不必为它多装一个包。代价是功效公式要自己实现（约 20 行），收益是可审计。
- **不把方案文档当 `--check` 的输入**：文档在另一个仓库（docs-research），CI 读不到。
  `DOC_*` 常量作为文档镜像，能拦住「算法漂了」与「文档没跟上」两种情形；跨仓自动同步不可行。
- **不让 `--check` 自动修一侧**：那等于让尺子自己改刻度。改法只有一条固定路径：
  先确认现算正确 → 改文档 → 同步 `DOC_*`，并在 PR 里写明三处一起改。
- **不在文档里保留 n=37 的 27 pp**：手算值偏 4.9 pp。留着会让人以为「几十题能拦 ~27 pp」，
  而真实判别力是 32 题 ≥34.1 pp、37 题 ≥31.9 pp —— 方向不变但**更钝**，扩题（B4）的必要性更强。
  这是本次唯一一处**文档数字被脚本推翻**的地方，已在 §3.3 加显式修正说明。
- **不把配对表留在 37 题**：计分集已由 T00 裁决②③改成 32 题（`meta/scoring-set.json`），
  功效必须按新题量算；旧表以括注保留，便于对照，但不再是判据。
- **不做「ε 样本内估计」兜底**：§5.2 明确样本内估计有偏（真实通过率 0.7 的题也有约 34%
  概率 3/3 全过）。`--holdout` 缺省时取预登记下限 0.10 并在输出里**明示来源**，
  ⛔ 不拿 k 份结果自己估 ε。

## 拿什么证明它生效了

- `python3 scripts/eval-stats.py --check` → 「✅ 三张表与文档冻结值一致」。
- 单测 27 条全绿；CI 清单内 4 个测试文件 `270 passed / 4 skipped`。
- **文档修订前后的对账证据（2026-11-04 实测）**：
  - §3.3 表① n=37：文档 27 pp → 脚本 **31.9 pp**（差 4.9 pp，不是舍入）；
    n=100/300/500：19/11/9 → 19.7/11.3/8.7；新增 n=32 → **34.1 pp**。
  - §3.3 表② 按 32 题：不一致 3 / 6 / 10 条，判显著 6 : 0 与 9 : 1，
    净回退 18.8 pp / 25.0 pp（旧 37 题表为 4 / 7 / 11、7 : 0、10 : 1、19 pp、24 pp）。
  - §5.2 m 表 15 格 + 检出概率 5 个：**逐格一致**，无需修改。
- **变异自证（3 处，见 `scripts/tests/test_eval_stats.py`）**：
  - 把 `DOC_UNPAIRED[37]` 改回文档旧值 27.0 ⇒ `test_check_detects_drift` 变红（证明对账不是恒绿）；
  - 把 `DOC_M[(10, 15)]` 改成 3 ⇒ `test_check_detects_m_drift` 变红；
  - 换工作点 p（0.10 vs 0.378）⇒ `test_unpaired_depends_on_p_base` 的单调关系不成立、变红。
- **边界自证**：`test_m_boundary_is_exact_not_float` 锁住 |S|=10、ε=0.15 的 0.04997 ——
  这一格用浮点实现会随累加顺序翻转，精确有理数路径不会。
