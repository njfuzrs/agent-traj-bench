# 为什么必须有这份清单：
#   支点仓库 person/sid-code 自身就是一个 coding agent，仓库内入库了

#   与 evals/bench 相关。三个后果：
#     1. 自指污染 —— 用「开发 coding agent 的轨迹」评测 coding agent，素材与
#        评测对象同源；
#     2. 答案泄漏 —— agent 解题时可直接读到评测机制本身；
#     3. 分布扭曲 —— L1A 走 gold-patch 路线会天然超采「修评测脚本」这类 task。

# 使用契约（强制，非建议）：
#   S4 分诊时，任务单元的 files_touched 若命中以下任一前缀，该单元一律淘汰，
#   不进候选池。淘汰原因记为 E_SELF_REFERENTIAL。
#   同时在 dataset card 的 Limitations 首条披露本约束。
